# noxif

A simple tool to strip EXIF metadata from images, built with Nuxt 4 and Piexifjs. Runs entirely in the browser, ensuring your images never leave your device.

<img width="824" height="542" alt="image" src="https://github.com/user-attachments/assets/708542e3-5d55-4a19-bc60-559443aa2426" />


Works with:

- JPG
- JPEG
- TIFF

## Setup

Install deps:

```bash
bun i
```

Run dev server at: `http://localhost:3000`

```bash
bun run dev
```
